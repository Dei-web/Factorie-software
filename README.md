# Harness Project

A Python project using strands-harness with NVIDIA Nemotron model.

## Structure

- `src/harness/main.py` - Main entry point
- `src/harness/model.py` - Model configuration (NVIDIA Nemotron)
- `pyproject.toml` - Project configuration
- `.env` - Environment variables (NVIDIA_API_KEY)

## Running

```bash
cd /home/dei/Proyectos/Harness
python -m harness.main
```
